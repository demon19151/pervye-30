# Первые 30

Платформа адаптации первокурсника: **30 дней** с наставником и небольшой группой.

Сценарий MVP — первые недели в университете. Участник закрывает шаги недели, может спросить ИИ-помощника или написать наставнику лично. Наставник видит прогресс и сигнал, если кто-то застрял.

В интерфейсе роль называется **Наставник**. В коде это по-прежнему `curator`.

---

## Запуск

Нужны Node.js 18+ и npm.

```bash
npm install
```

Создай файл `.env.local` в корне:

```
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
```

Значения — из проекта Supabase (Settings → API). Без них приложение не стартует: клиент ходит в Postgres, а не в localStorage.

Для ИИ-помощника (чат на `/ask` и виджет) дополнительно:

```
LLM_API_KEY=
LLM_BASE_URL=https://openrouter.ai/api/v1
LLM_MODEL=
```

Опционально для гибридного поиска по базе знаний: `EMBEDDINGS_API_KEY`, `EMBEDDINGS_BASE_URL`, `EMBEDDINGS_MODEL`, `EMBEDDINGS_DIM`.

На Vercel те же переменные задаются в Project Settings → Environment Variables. `NEXT_PUBLIC_*` вшиваются на сборке — после смены нужен redeploy.

```bash
npm run dev
```

Откроется [http://localhost:3000](http://localhost:3000).

```bash
npm run build
npm run start
npm test
```

## Что умеет MVP

- Недельные задания: закрыть шаг, ответить кнопкой или отметить, что нужна помощь.
- Личные сообщения участник ↔ наставник (группа их не видит).
- ИИ-помощник по базе `knowledge/*.md` (учёба и университет).
- Календарь мероприятий: наставник добавляет встречи, участник отмечает «пойду / не пойду».
- Прогресс, итоги программы, отзыв о наставнике.
- Панель наставника: обзор, кто требует внимания, задания, вопросы, настройки комнаты.

Убрано из продукта: ежедневный чек-ин настроения, общий чат группы, объявления наставника в ленту.

## Как устроен код

```
app/                 маршруты Next.js App Router
components/          UI и доменные блоки
lib/services/        задания, прогресс, поддержка, аккаунты
lib/supabase/        клиент и запись в Postgres
lib/bot/             ИИ-помощник (LLM + поиск по knowledge/)
knowledge/           база знаний для ассистента
supabase/migrations/ схема и демо-данные
```

Данные комнаты живут в **Supabase Postgres**. Сессия устройства (`pervye-30:session`) — в `localStorage`.

Наставник видит участника в «Требуют внимания», если не закрыты обязательные шаги прошлой недели или участник сам попросил помощь. Пороги — в `lib/services/statsService.ts` и `lib/services/taskService.ts`.

Прогресс считается по обязательным заданиям уже начавшихся недель, а не по всем 30 дням сразу.
